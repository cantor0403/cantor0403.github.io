使用示例：怎样发布一篇数学文章

张哲

这是可删除的使用说明示例。它用于帮助你熟悉编辑流程，不是正式博客文章。

1. 写一篇文章

在 Publii 中打开 Posts，创建文章。建议先用可视化编辑器（WYSIWYG），输入标题、正文和分类。写到一半可以保存为草稿，预览满意后再发布。

你可以把研究札记、讲义和随笔分别设成标签；这个模板会把标签作为分类显示在侧栏。

2. 插入公式

行内公式可以写成 \(E(t)\)，它在正常正文中的效果是 \(E(t)\)。独立成行的公式可以使用 \[...\]。

下面是可以复制到正文中的公式文本：

\[
  \int_0^1 x^2\,\mathrm{d}x=\frac13.
\]

代码框里的内容会保留为代码。复制时把内容粘贴到普通段落里，再点击 Preview 查看数学排版。

模板也支持常见的 $...$ 和 $$...$$。为了避免普通金额中的美元符号被当成公式，数学文章优先采用 \(...\) 和 \[...\]。

定理框

复制另一篇排版示例中的定理框，替换标题和正文即可。也可以在 HTML 模式或 HTML 区块中使用以下结构：

<div class="theorem">
  <p class="theorem-title">定理 1</p>
  <p>在这里写定理陈述与 \(x\in\R\)。</p>
</div>

3. 添加 PDF

在 Tools → File Manager 的 media/files 中加入 PDF，然后在文章中添加指向该文件的链接。PDF 也会随网站同步发布。请使用简短的英文文件名，便于引用。

一篇文章可以先在网页中给出动机、摘要或关键计算，再链接到完整的 PDF。

4. 预览与发布

保存文章后，先预览。确认标题、公式和链接都正确，再点击 Sync your website。保存到电脑和同步到网站是两个步骤。

首次同步前，需要在 Server 设置中连接自己的 GitHub Pages。完整步骤见安装包中的中文指南。

5. 保留自己的副本

Publii 的文章和配置保存在自己的电脑中。Tools → Backups 可以导出完整备份；定期把备份再保存一份到其他位置。

GitHub 上主要是生成后的网页。电脑里的完整 Publii 备份，才方便换电脑后继续编辑。
